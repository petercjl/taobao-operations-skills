# 万相台无界洞察

## 依赖与授权

- `@petercjl/sycmcli >= 0.4.0`，能力 `business.registered_data.read`。
- 使用 sycmcli 为所选店铺管理的可见 Chrome。万相台登录或授权缺失时，打开该店铺浏览器让用户完成授权；凭证不导出、不写入文件。
- 只运行 sycmcli 注册的阿里妈妈操作。旧参考文档保留模块参数和输出字段定义，不作为绕过注册表的直连接口入口。

## 输入路由

- 行业解析：一级/二级类目、`dateType`。
- 竞争解析：明确二级类目 ID。
- 流量解析：店铺类目或全店、排行维度。
- 趋势速递：`tab`，可选用户确认的 `topicId`。

模块字段、词类型和返回结构见 `references/` 对应文档。

## 主线

1. 唯一解析店铺并检查万相台授权状态。
2. 按用户意图选择行业、竞争、流量或趋势流程；缺少类目/主题时先读取候选，再由用户确认。
3. 通过 sycmcli 注册操作执行取数；每次校验业务成功状态、模块 ID、类目/主题和返回数组。
4. 保留平台原始指数、排名、区间和标签；不把指数解释为真实金额或人数。
5. 输出趋势、竞争位置、机会词/主题、反证与最多 3 条验证建议。

## 输出

`store`、`module`、`scope`、`dateRange`、`categories/topics`、`rankings`、`signals[]`、`opportunities[]`、`actions[]`、`sourceOperations[]`、`dataGaps[]`。

## 异常与边界

- 若当前 sycmcli 未注册所需洞察模块，返回 `CAPABILITY_UNAVAILABLE` 并指出缺少的模块；不得执行旧商户脚本或任意 POST。
- 登录、授权、风控失败时停止，由用户处理后重试一次。
- 只读，不创建/修改推广计划、预算、收藏词或账户配置；完成后清理临时数据。

## 验收

类目或主题已确认；每个结论可回指到平台返回；脱敏区间、指数和缺失值未被改写。
