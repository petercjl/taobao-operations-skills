# 可二次 Query 技能目录

> 模型在猜你想问环节从此列表中动态选取最关联的技能推荐给用户。

| skillcode | name | 应用场景 |
|---|---|---|
| item-traffic-analysis | 商品流量来源分析 | 单品流量从哪些渠道来？各渠道占比如何？某个流量渠道的UV/转化率突然下降，需要诊断原因；分析搜索流量、推荐流量、付费流量的贡献占比；对比不同时间段的流量结构变化 |
| sku-sales-analysis | 商品SKU销售分析 | 哪个SKU卖得最好？各SKU的销售占比如何？分析SKU的价格带分布与销量关系；识别需要补货或清仓的SKU；优化SKU结构，淘汰低效SKU |
| shop-core-potential-item-analysis | 核心潜力商品分析 | 店里哪些商品有打爆潜力？值得重点推广？新品上架后如何判断是否有潜力？从全店商品中筛选出值得加大推广投入的款；分析潜力商品的核心优势和改进方向 |
| shop-potential-product-analysis | 潜力品分析 | 店里哪些商品有增长潜力？分析商品的流量增速和转化趋势；识别值得加大推广投入的潜力款；制定潜力品打爆策略 |
| item-gallery-analysis | 商品主图分析 | 商品主图点击率低，哪张图效果不好？分析5张主图各自的引流和转化表现；主图视频的效果如何？播放率和转化率怎样？对比不同主图的点击表现，决定是否需要换图 |
| item-search-traffic-diagnosis | 商品搜索流量分析 | 商品搜索流量为什么下降了？哪些搜索词在带来流量？哪些词排名掉了？搜索转化率低于行业均值，如何优化？分析搜索词与标题的匹配度，优化标题关键词 |
| item-promotion-analysis | 商品付费推广分析 | 商品推广效果怎么样？ROI达标了吗？分析直通车/引力魔方的推广数据；推广花费高但转化低，问题出在哪？优化推广策略，降低获客成本 |
| item-traffic-structure-analysis | 商品流量结构分析 | 商品流量结构是否健康？免费/付费占比合理吗？各流量渠道的质量对比（转化率、跳失率）；流量结构变化趋势分析；优化流量结构，提升免费流量占比 |
| competitor-item-analysis | 竞品对比分析 | 我的商品和竞品比差距在哪？竞品为什么卖得比我好？对比竞品和本品的流量来源、转化率、价格策略；从竞品分析中找到优化方向和差异化策略 |
| item-ops-event-impact-analysis | 商品运营动作分析 | 换了主图后效果怎么样？点击率提升了吗？改价后销量有什么变化？优化标题后搜索流量有没有增长？评估每次运营动作的ROI，指导后续运营决策 |
| shop-core-index-analysis | 店铺核心指标分析 | 店铺核心经营指标怎么样？支付金额、访客数、转化率趋势分析；与同行同层平均和优秀对比；找出指标异常和改进方向 |
| item-recommendation-creative-analysis | 商品推荐素材诊断 | 猜你喜欢渠道的创意素材效果如何？分析推荐渠道各创意素材的点击率和转化率；优化推荐渠道的创意图，提升点击率；对比不同创意素材在推荐渠道的表现 |
| daily-shop-inspection | 店铺每日巡检 | 今天店铺经营情况怎么样？每日巡检，快速发现数据异常；核心指标、流量、交易、退款全面检查；生成每日经营巡检报告 |
| shop-new-item-analysis | 店铺新品分析 | 新品上架后表现怎么样？分析新品的流量、转化、收藏加购数据；评估新品市场接受度和潜力；对比不同新品的表现，筛选潜力款 |
| competitor-comparison-action-tracking | 竞争对比与动作跟踪 | 竞店最近有什么运营动作？竞品流量和转化对比分析；分析流失去向，找出流失原因；生成竞争对比分析报告 |
| shop-inspection-problem-info | 店铺巡检问题详情 | 店铺巡检发现了什么问题？查看问题的详细信息和影响程度；获取问题修复建议；跟踪问题解决进度 |
| shop-core-product-analysis | 店铺核心商品分析 | 店铺哪些是核心主力商品？核心商品的流量、转化、退款表现；识别需要重点维护的核心商品；分析核心商品的生命周期阶段 |
| market-blue-ocean-opportunity-mining | 市场蓝海机会挖掘 | 市场上有哪些蓝海机会？挖掘蓝海关键词和蓝海类目；分析蓝海市场的搜索人气和竞争度；发现低竞争高需求的市场机会 |
| item-loss-to-competitors-analysis | 商品流失竞品分析 | 我的商品访客流失到哪些竞品了？分析流失原因和流失金额；找出导致流失的关键因素；制定挽回流失访客的策略 |
| item-benchmark-analysis | 商品经营数据对标分析 | 我的商品数据和同行优秀比差距多大？各项指标（转化率、客单价、退款率）与行业标杆对比；找出最需要优化的指标，设定改进目标；定期对标行业水平，跟踪改进进度 |
| competitor-shop-analysis | 竞店对比分析 | 竞品店铺的经营策略是什么？竞店的流量从哪来？主要卖哪些商品？对比本店与竞店的整体经营数据；学习竞店的成功经验，制定竞争策略 |
| comprehensive-customer-analysis | 客户综合分析 | 店铺客户画像是什么样的？分析客户分群和购买行为特征；复购率和客户忠诚度分析；识别高价值客户和流失风险客户 |
| item-competitors-add-suggestion | 商品竞品添加建议 | 应该关注哪些竞品？系统推荐值得监控的竞品；完善竞品监控列表；发现新的潜在竞争对手 |
| shop-customer-segmentation-analysis | 店铺客户分群分析 | 店铺客户可以怎么分群？新客和老客的购买行为差异；识别高价值客户群体；制定分群差异化运营策略 |
| category-top-items-profile | 类目TOP商品画像分析 | 类目TOP商品有什么共同特征？分析爆款商品的价格、属性、卖点组合；总结类目爆款画像，指导新品开发；对比本品与TOP商品的差距 |
| category-keyword-analysis | 类目关键词分析 | 这个类目有哪些热搜关键词？挖掘类目蓝海词和飙升词；分析关键词搜索人气和竞争度；为商品标题优化提供关键词参考 |
| category-attribute-analysis | 类目属性分析 | 这个类目的消费者最关注哪些属性？分析类目属性分布，找出影响转化的关键属性；选品时参考类目热门属性组合；优化商品属性填写，提升搜索匹配度 |
| category-top-shops-profile | 类目TOP店铺画像分析 | 这个类目头部店铺是怎么经营的？分析TOP店铺的商品结构和定价策略；学习头部店铺的流量获取方式；对比本店与TOP店铺的差距 |
| shop-core-audience-profile-analysis | 店铺核心人群画像分析 | 店铺核心客户是什么样的？分析客户性别、年龄、城市分布；了解客户消费层级和偏好；精准定位目标客群，指导营销投放 |
| shop-paid-promotion-analysis | 店铺付费推广分析 | 店铺付费推广效果怎么样？各推广渠道的花费和ROI对比；分析付费推广的引流效果；优化付费推广策略，提升ROI |
| category-trend-opportunity-analysis | 类目趋势机会分析 | 这个类目未来趋势怎么样？发现类目中的蓝海细分市场；分析类目增速和新品机会；找到趋势属性和新兴需求 |
| shop-competitors-add-suggestion | 店铺竞品添加建议 | 应该关注哪些竞争店铺？系统推荐值得监控的竞店；完善竞店监控列表；发现新的潜在竞争对手店铺 |
| shop-traffic-channel-analysis | 店铺流量渠道分析 | 店铺流量从哪些渠道来？各流量渠道的UV、PV、转化率对比；分析流量结构健康度；优化流量渠道配置，提升免费流量占比 |
| category-price-band-analysis | 类目价格带分析 | 这个类目哪个价格段卖得最好？分析类目价格带分布和竞争格局；找到蓝海价格区间，避开红海竞争；为商品定价提供数据参考 |
| shop-monthly-sales-analysis | 店铺月度销售分析 | 这个月销售情况怎么样？月度销售趋势和同比环比分析；分析月度类目构成和价格带构成；对比月度销售目标完成情况 |
| category-best-selling-items-analysis | 类目热销商品分析 | 这个类目哪些商品卖得最好？分析热销商品的共同特征（价格、属性、卖点）；发现类目爆款趋势，指导选品方向；对比热销商品与本品的差距 |
| weekly-or-monthly-store-performance-reports | 店铺经营周/月报 | 帮我生成一份店铺周报/月报；周期性经营总结，涵盖全维度数据；对比上期数据，分析变化趋势；生成可视化经营报告 |
| item-available-competitor-query | 商品可选竞品查询 | 我的商品有哪些竞品可以对标？查询系统推荐的竞品列表；了解竞品的价格、销量等基础信息；为竞品对比分析选择对标对象 |
| shop-refund-analysis | 店铺退款分析 | 店铺退款率怎么样？有没有异常？分析退款原因分布和退款商品TOP；退款时长分析和行业对标；制定降退策略和召回机会 |
| sycm-flow-shopsource-helper | 生意参谋店铺流量来源分析 | 店铺流量具体从哪些来源来？分析各流量来源的指标趋势和同行对比；新客/老客/非买家流量来源拆分；直播流量来源趋势分析 |
| sycm-item-rank-helper | 生意参谋商品排行分析 | 店里哪些商品卖得最好？查询商品销量/销售额/访客排名；单品深度分析：核心指标、趋势、流量来源；分析SKU销售和搜索词表现 |
