# 竞争动态追踪

本 Skill 编排店铺或商品竞争分析并管理业务追踪状态；不依赖远程 Agent。

## 依赖与状态

- 店铺级依赖 `competitor-shop-analysis`；商品级依赖 `sycm-item-competitor-analysis`。
- 底层 `@petercjl/sycmcli >= 0.4.0`，能力 `business.registered_data.read`。
- 输入：`store`、竞对稳定 ID、基准期、观察期、跟踪维度、可选项目目录。
- 追踪文件由用户指定项目目录持有；首次创建前确认路径。更新已有文件时先读元数据并生成恢复备份。

## 主线

1. 校验两期长度、口径、对象集合一致；新增/移除竞对单列，不混入连续变化。
2. 加载对应依赖 Skill，分别取得基准期和观察期的真实数据。
3. 计算同口径变化：核心指标、趋势、渠道、搜索词、头部商品或竞品来源。`null` 不视为 0。
4. 将平台运营摘要、活动亮点、商品/流量变化分成“已观测动作”“同时发生现象”“待验证假设”。
5. 对每条显著异动记录对象、指标、前值、后值、变化、证据操作和置信度。
6. 形成追踪动作：负责人/截止时间由用户提供；未提供时只给建议，不代填组织信息。

## 输出

`baseline`、`observation`、`scope`、`changes[]`、`observedActions[]`、`hypotheses[]`、`followUps[]`、`evidence[]`、`dataGaps[]`，可选保存 Markdown/JSON 追踪文件。

## 边界与验收

- 只读外部平台；本地追踪文件写入需明确目标路径，覆盖前备份。
- 不把同时变化认定为因果，不自动关注竞对或执行追赶动作。
- 同一异动不能被重复计数；所有变化均有前后期证据。
