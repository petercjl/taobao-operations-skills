# 品类核心决策属性参考表

> **作用**：为 Step 4「模型提取商品属性」提供属性分类标准与关键词词典，确保不同任务的卖点归一化口径一致。
> **使用方式**：模型读取标题后，**严格匹配**下表关键词，归一到对应类别；同义词需归一化为表内主词。

## 一、占比口径说明（写入报告须显式标注）

> **重要**：本技能按价格带分别拉取 top100，整体样本量 = 价格带档数 × 每档实际抓取数（例如 4 档 × 100 = 400）。所有跨价格带聚合的占比分母均为「实际抓取的总样本量」，由 `analyze_market_share.py` 动态计算并写入 `market_share.total_items`。

- **商品个数占比** = 命中维度的商品数 / **实际抓取的总样本量**（动态值，例如 4 档 × top100 = 400；如某档不足 100 条以实际为准）
- **支付买家数占比** = 命中维度商品的 `payByrCnt` 下界累加 / 全部样本商品 `payByrCnt` 下界累加总和
  - 因生意参谋接口返回的 `payByrCnt` 是区间值（如 "8万 ~ 12万"），统一按下界（min）取数
  - **报告必须显式标注「该口径为毛估」**
- **头部集中度** = 该价格带 Top N（默认 N=10，由 `analyze_market_share.py --top-n` 控制）商品的 `payByrCnt` 下界累加 / 该价格带全量商品 `payByrCnt` 下界累加，反映该价格带是否被头部商品垄断（卖点维度同理：该卖点下 Top N / 该卖点全部商品）

## 二、8 大属性类别（通用框架）

| 类别 | 含义 | KANO 默认层 |
|------|------|-----------|
| 功效 | 商品解决用户问题的能力 | 期望型 |
| 成分 | 关键原料/材质 | 期望型（部分稀有成分→兴奋型） |
| 场景 | 使用场景/时机 | 期望型 |
| 人群 | 目标人群标签 | 期望型 |
| 工艺 | 生产工艺/技术 | 兴奋型 |
| 资质 | 认证/口碑/榜单 | 基础型 |
| 赠品 | 附加价值/服务 | 兴奋型 |
| 价格信号 | 标题中的价格/折扣信号 | 无差异型（不参与卖点 KANO） |

> KANO 层调整规则：
> - **基础型**：不可缺失的卖点（如品类标准认证、安全资质）
> - **期望型**：用户主动比较的卖点（功效/成分/场景）
> - **兴奋型**：超预期惊喜的卖点（独家工艺/创新场景/赠品）
> - **无差异型**：不影响购买决策的卖点（如纯价格信号）

## 四、品牌识别规则

1. **优先使用店铺名**：从店铺名中提取品牌（如「图拉斯旗舰店」→ 品牌「图拉斯」、「优衣库官方旗舰店」→ 品牌「优衣库」）。店铺名是最可靠的品牌信号
2. **标题品牌需排除适配词干扰**：3C 数码配件等品类的标题常出现适配品牌（如「适用于华为/苹果手机壳」），这些是兼容性描述而非产品所属品牌，**禁止**将适配对象误判为品牌
3. **常见品牌大小写归一**：英文品牌统一用官方写法（LANCOME→兰蔻、HUAWEI→华为）
4. **白牌识别**：店铺名和标题均无法识别品牌时，`brand` 填 `null`（不要填「白牌」字样，由脚本统计后归类）
5. **识别优先级总结**：店铺名品牌 > 标题中明确的自有品牌词（排除适配/兼容描述） > `null`

## 五、KANO 分级建议（写入 `kano_layer` 字段）

| 卖点典型 | KANO 层 | 说明 |
|---------|--------|------|
| 安全认证、品类基础功效（洗面奶能洗干净） | 基础型 | 必备项，缺失会被惩罚 |
| 高频功效（保湿、美白）、热门成分（玻尿酸） | 期望型 | 用户主动比较，多了好评，少了无感 |
| 黑科技、独家工艺、创新场景 | 兴奋型 | 超预期，是差异化壁垒来源 |
| 单纯价格信号、模糊宣传 | 无差异型 | 不影响决策，不计入卖点占比 |

模型在归类时**优先取最高频卖点的 KANO 层**作为该商品的代表层。

## 六、电商版 KANO 量化规则（脚本初判 + 模型终判）

> [analyze_market_share.py](../scripts/analyze_market_share.py) 针对每个卖点计算下列 5 个量化指标，再按 R0→R4 优先级验证规则命中、得出 **kano_initial_suggestion**；最终的 KANO 层由模型在 Step 5.1 结合语义与类目权威信号（item-selling-point-alg-strategy）二次决策。

### 6.1 五个量化指标定义

| 符号 | 全名 | 计算口径 |
|------|------|----------|
| **D** | 需求强度 Demand | 含该卖点商品的 `payByrCnt` 下界累加 / 全量样本 `payByrCnt` 下界累加 |
| **P** | 供给普及度 Penetration | 含该卖点商品数 / 全量样本商品数（即覆盖率） |
| **R** | 偏好溢价 Premium | 该卖点商品价格带中位数代价均值 / 全品类价格带代价均值（价格带代价＝中位数，开口区间取 base × 1.5）|
| **H** | 头部支撑 Head | 该卖点 top10 `payByrCnt` 下界累加 / 该卖点全量商品 `payByrCnt` 下界累加（即头部集中度）|
| **E** | 价格溢价 Excess | 该卖点商品所在价格带均价 / 全品类均价（与R互补，衡量是否集中在高价带）|

### 6.2 脚本初判规则（优先级 R3 > R2 > R1 > R4 > R0）

| 规则 ID | 初判 KANO | 命中条件（默认阈值，AND） |
|--------|------------|----------------------------|
| **R3** | 兴奋型 | D ≥ 0.08 且 P < 0.20 且 R ≥ 1.5 且 H ≥ 1.3 |
| **R2** | 期望型 | D ≥ 0.30 且 0.20 ≤ P ≤ 0.70 且 R > 1.15 |
| **R1** | 基础型 | D ≥ 0.50 且 P > 0.60 且 0.85 ≤ R ≤ 1.15 |
| **R4** | 无差异型 | D < 0.05 或 （P > 0.60 且 R ≤ 0.95） |
| **R0** | 未命中 | 以上均不命中时占位，交由模型终判 |

输出到 `market_share.json` 的 `selling_point_share[*]`：

```json
{
  "selling_point": "20W快充",
  "D": 0.873, "P": 0.805, "R": 1.08, "H": 0.51, "E": 1.03,
  "kano_rule_hit": "R1",
  "kano_initial_suggestion": "基础型",
  "rule_match_detail": { "R1": true, "R2": false, "R3": false, "R4": false }
}
```

### 6.3 三档阈值预设（[config/default_config.json](../config/default_config.json) `kano_thresholds.profile`）

| profile | 适用场景 | 与 default 差异 |
|---------|---------|---------------|
| `default` | 广谱标品类目（默认） | 上表阈值 |
| `loose_excitement` | 新兴 / 小众品类 | R3 的 P 上限放到 0.30，R 下调到 1.30，D 下调到 0.05 |
| `strict_basic` | 高度标准化（3C 配件等） | R1 的 P 下限提到 0.70，D 下限提到 0.60 |

### 6.4 类目权威放宽（item-selling-point-alg-strategy）

当某卖点在类目决策属性中 `is_core_factor=true` 时，脚本在判定初判时对 D 与P 阈值放宽 20%（仅限初判），避免品类核心属性被错判为无差异型。该信号同时写入 `category_strategy_signal` 子字段，供模型终判参考。

### 6.5 模型终判输出结构

`kano_final.json` 的结构定义与强制规则以 [schemas.md `## kano_final.json`](schemas.md) 为唯一事实源（注意 `kano_final` 必须是 dict，不是字符串）。Excel 的「KANO 详细评判」sheet 会高亮 `agree_with_rule=false` 的覆盖行。
